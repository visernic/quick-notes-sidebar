# Security Policy

## Supported Versions

We currently support the latest version of the extension.

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to **support@visernic.com**. All security vulnerability reports will be promptly addressed.

Please do **NOT** create a public GitHub issue for security vulnerabilities.
